# play-poker

Play free poker against computer opponents directly from this program. This lightweight implementation allows up to 4 players to participate in a simulated game featuring full chips and betting logic.

## 🃏 Features

* **Single-Player vs AI:** Play against computer opponents with simulated decision-making.
* **Up to 4 Players:** Support for up to 4 active spots at the table.
* **Betting Mechanics:** Full implementation of betting cycles, including chips management.
* **100% Free:** Completely local, offline poker experience.

## 📂 Repository Structure

* `poker3/`: Contains the core project files and executable scripts for the poker program.

## 🚀 Getting Started

### Prerequisites

Depending on the underlying language of the application, make sure you have the required environment installed (e.g., Python, Node.js, or Java). 

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com
   ```

2. Navigate into the project directory:
   ```bash
   cd play-poker
   ```

3. Explore the `poker3` directory to launch the main script or game execution file.

## 🎮 How to Play

1. Set up your game or initial table setup.
2. Receive your cards and manage your simulated chip balance.
3. Test your skills against the built-in AI bots through standard check, bet, raise, and fold mechanics.
